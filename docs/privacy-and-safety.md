# 隐私与安全

## 数据边界

- 交易数据库、账户数据、历史流水和工具日志保存在用户本机；
- 模型 API Key 使用独立文件保存，不写入业务数据库；
- 本地访问令牌和敏感文件使用最小文件权限；
- 备份、日志和历史对话按规则自动清理；
- 本公开仓库不包含任何真实交易数据和密钥。

## 模型边界

- 模型只接收回答当前问题所需的最小上下文；
- 账号、终端、订单、备注和密钥等字段在外发前裁剪或脱敏；
- 工具数据与模型判断分开呈现；
- 数据过期、缺失或来源不可用时，模型不能把缺失值解释为真实状态；
- 模型不能直接修改账户或执行交易。

## 交易边界

AUREVAN 当前默认只读盯守和分析。银行成交录入只记录用户已经完成的真实交易；任何需要操作权限的任务必须经过用户明确授权。系统不提供绕过授权的自动执行路径。

## 公开边界

公开案例只展示产品逻辑、架构、测试方法和经过脱敏的视觉素材。私有源码、提示词、模型配置、账户信息、交易数据与可执行组件不进入公开仓库。
